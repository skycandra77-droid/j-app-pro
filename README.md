# LaundryPOS - Kasir Digital untuk Laundry 🧺💰\n\nAplikasi kasir digital modern untuk bisnis laundry dengan fitur PWA (Progressive Web App) sehingga dapat diinstal langsung di HP, tablet, dan laptop tanpa perlu app store.\n\n## ✨ Fitur Utama\n\n### 🧾 Kasir\n- **Interface yang intuitif**: Desain modern dan mudah digunakan\n- **Manajemen Layanan**: Tambah, edit, dan hapus layanan dengan harga fleksibel\n- **Icon Picker**: Pilih icon emoji untuk setiap layanan saat menambah item baru\n- **Keranjang Pesanan**: Lihat semua item yang dipesan dengan detail harga\n- **Diskon**: Aplikasikan diskon dalam persen\n- **Metode Pembayaran**: Tunai, Transfer, QRIS, dan Pending\n- **Pencarian**: Cari layanan dengan mudah\n- **Filter Kategori**: Pisahkan layanan berdasarkan kategori\n\n### 📊 Laporan\n- **Statistik Penjualan**: Lihat total pendapatan, rata-rata per transaksi\n- **Riwayat Transaksi**: Detail lengkap setiap transaksi (tanggal, pelanggan, metode pembayaran)\n- **Filter Periode**: Lihat laporan harian, mingguan, bulanan, atau semua waktu\n- **Export CSV**: Download data laporan ke format spreadsheet\n- **Order Pending**: Pantau semua order yang belum selesai\n\n### 💸 Pengeluaran (BARU!)\n- **Catat Pengeluaran**: Tambah pengeluaran operasional (bahan bakar, gaji, dll)\n- **Statistik**: Lihat total pengeluaran dalam periode tertentu\n- **Riwayat**: Lihat semua pengeluaran dengan tanggal dan keterangan\n- **Filter**: Filter pengeluaran berdasarkan periode waktu\n\n### ⚙️ Pengaturan\n- **Informasi Toko**: Atur nama toko, tagline, dan nomor rekening\n- **Manajemen Layanan**: Edit semua layanan dengan:\n  - **Icon Picker**: Pilih dari 40+ emoji icon\n  - Nama layanan\n  - Harga\n  - Kategori\n  - Satuan (per kg, per item, dll)\n\n### 📱 PWA - Instalasi di Semua Device\n\n**Desktop (Windows/Mac/Linux):**\n1. Buka https://jlaundrykilat-bot.github.io/JPOS/\n2. Klik icon install (⬇️ + tanda kotak) di address bar\n3. Klik \"Install\"\n4. Aplikasi akan tersedia di desktop\n\n**Smartphone Android:**\n1. Buka di Chrome: https://jlaundrykilat-bot.github.io/JPOS/\n2. Tap menu (⋮) > \"Install app\"\n3. Tap \"Install\"\n4. Aplikasi akan tersedia di home screen\n\n**iPhone/iPad:**\n1. Buka di Safari: https://jlaundrykilat-bot.github.io/JPOS/\n2. Tap share icon (kotak dengan panah) di bawah\n3. Pilih \"Add to Home Screen\"\n4. Ketik nama dan tap \"Add\"\n\n### 🌐 Offline Support\n- Aplikasi tetap bisa digunakan meski offline\n- Data otomatis tersimpan di localStorage browser\n- Semua data sinkron saat online kembali\n\n## 🚀 Cara Menggunakan\n\n### 1. Membuka Aplikasi\n- **Web**: https://jlaundrykilat-bot.github.io/JPOS/\n- **Installed App**: Buka dari desktop/home screen\n\n### 2. Setup Awal (Pengaturan)\n1. Masuk ke tab **⚙️ Pengaturan**\n2. Atur **Informasi Toko**:\n   - Nama toko Anda\n   - Tagline\n   - Nomor rekening (untuk transfer)\n3. Sesuaikan **Edit Layanan & Harga**:\n   - Klik icon emoji untuk mengubah\n   - Edit nama dan harga\n   - Tambah layanan baru dengan tombol **+ Tambah Layanan**\n4. Klik **💾 Simpan**\n\n### 3. Menggunakan Kasir\n1. Masuk ke tab **🧾 Kasir**\n2. **Cari Layanan**:\n   - Ketik nama layanan di kolom pencarian\n   - Pilih kategori di filter\n3. **Tambah ke Keranjang**:\n   - Klik kartu layanan untuk menambahkan\n   - Gunakan tombol +/- untuk mengubah jumlah\n4. **Isi Data Pelanggan**:\n   - Nama (wajib untuk pending, opsional untuk bayar)\n   - No. HP (opsional)\n5. **Aplikasikan Diskon** (jika ada):\n   - Masukkan persentase diskon\n6. **Pilih Metode Pembayaran**:\n   - **💵 Tunai**: Masukkan uang yang diterima, kembalian otomatis terhitung\n   - **🏦 Transfer**: Tampilkan nomor rekening ke pelanggan\n   - **📱 QRIS**: Tampilkan kode QRIS\n   - **🕐 Pending**: Simpan untuk pembayaran nanti\n7. **Klik Bayar / Simpan Pending**\n8. **Selesai**: Data otomatis tersimpan\n\n### 4. Melihat Laporan\n1. Masuk ke tab **📊 Laporan**\n2. Pilih **Transaksi** atau **Pending**\n3. Filter periode: Hari Ini, 7 Hari, 30 Hari, atau Semua\n4. Lihat statistik dan riwayat transaksi\n5. Export ke CSV jika perlu\n\n### 5. Mencatat Pengeluaran\n1. Masuk ke tab **💸 Pengeluaran**\n2. Klik **⬇️ Export CSV** → **⬇️ + Tambah Pengeluaran**\n3. Isi keterangan (misal: \"Bahan bakar\")\n4. Isi jumlah rupiah\n5. Klik **💾 Simpan**\n6. Lihat riwayat dan analisis pengeluaran\n\n## 💾 Data & Storage\n\n- Semua data disimpan di **localStorage** browser\n- Data tidak naik ke cloud, aman di perangkat lokal Anda\n- Backup otomatis jika Anda menggunakan sync browser\n- Untuk migrasi: Export CSV atau backup localStorage\n\n## 🎨 Desain & UX\n\n- **Modern**: Desain minimalis dengan palet warna yang menyenangkan\n- **Responsive**: Menyesuaikan dengan ukuran layar apa pun\n- **Cepat**: Optimasi performa untuk loading instant\n- **Accessible**: Support dark mode (via sistem operasi)\n- **Multilingual**: Teks dalam Bahasa Indonesia\n\n## 🔧 Tech Stack\n\n- **HTML5**: Struktur markup\n- **CSS3**: Styling modern dengan CSS variables\n- **JavaScript (Vanilla)**: Logic tanpa dependency besar\n- **Service Worker**: Untuk offline support\n- **LocalStorage API**: Penyimpanan data lokal\n- **Web Manifest**: PWA configuration\n- **jsPDF**: Export invoice (opsional)\n\n## 📁 Struktur File\n\n```\nJPOS/\n├── index.html          # File utama aplikasi\n├── manifest.json       # PWA manifest\n├── sw.js              # Service Worker\n├── laundry-pos.html   # Versi lama (deprecated)\n└── README.md          # Dokumentasi ini\n```\n\n## 🐛 Troubleshooting\n\n### Aplikasi tidak bisa diinstal\n- Pastikan URL di `https://` (bukan `http://`)\n- Gunakan browser terbaru (Chrome 88+, Firefox 78+, Safari 15+)\n- Refresh halaman dan coba lagi\n\n### Data hilang\n- Cek localStorage di DevTools (F12 > Application > Local Storage)\n- Jangan clear cache/cookies aplikasi\n- Backup data dengan export CSV secara berkala\n\n### Offline tidak bekerja\n- Pastikan Service Worker terdaftar (F12 > Application > Service Workers)\n- Akses satu kali saat online terlebih dahulu\n- Refresh halaman\n\n## 🚀 Update & Maintenance\n\n- Aplikasi akan auto-update saat ada versi baru\n- Fitur baru akan ditambah secara berkala\n- Lapor bug atau request fitur di GitHub Issues\n\n## 📝 Tips & Trik\n\n1. **Keyboard Shortcut**:\n   - Hapus semua item di keranjang: Klik \"Hapus Semua\"\n   - Clear data: Buka DevTools > Application > Clear Storage\n\n2. **Optimasi Data**:\n   - Export CSV setiap bulan untuk backup\n   - Pantau pengeluaran vs pendapatan di laporan\n\n3. **Ekspor & Analisis**:\n   - Gunakan Excel/Google Sheets untuk analisis mendalam\n   - Buat grafik tren penjualan\n   - Monitor metode pembayaran yang paling populer\n\n## 📞 Support\n\nJika ada pertanyaan atau butuh bantuan:\n1.
